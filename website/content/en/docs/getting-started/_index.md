Start here if you are new to Joulie.

**Prerequisites**: Kubernetes 1.26+, Helm 3+ and cluster-admin access. The [Quickstart]({{< relref "/docs/getting-started/01-quickstart.md" >}}) lists what Joulie needs on the cluster.

Read the pages in this order:

1. [Core Concepts]({{< relref "/docs/getting-started/00-core-concepts.md" >}}) - the components and the control loop
2. [Quickstart]({{< relref "/docs/getting-started/01-quickstart.md" >}}) - install and verify
3. [Tutorials]({{< relref "/docs/getting-started/04-tutorials.md" >}}) - six guided tours, the first three with only Docker
4. [Pod Compatibility]({{< relref "/docs/getting-started/03-pod-compatibility.md" >}}) - workload class annotations
5. [Agent Runtime Modes]({{< relref "/docs/getting-started/02-agent-runtime-modes.md" >}}) - DaemonSet, pool and emulated modes
6. [Configuration Reference]({{< relref "/docs/getting-started/05-configuration-reference.md" >}}) - every setting
7. [Upgrading]({{< relref "/docs/getting-started/06-upgrading.md" >}}) - the v0.2 to v0.3 checklist
8. [Alerts and Runbooks]({{< relref "/docs/getting-started/07-runbooks.md" >}}) - what to do when an alert fires
